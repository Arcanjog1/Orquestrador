# Cenário da taverna

Três assets originais gerados por ImageGen, sem texto nem interface incorporada:

- `tavern.png`: parede de pedra frontal, vigas, estantes, plantas e lanternas; fundo externo da aplicação.
- `forest.png`: clareira vista de cima, árvores, rio e pontes; fundo do mapa funcional.
- `parchment-frame.png`: papel vazio com borda de madeira e cantos metálicos; `border-image` preserva os cantos sem deformar os controles.

Direção comum: pixel art de RPG de 16 bits, pixels definidos, materiais quentes, sem desfoque. As imagens de referência orientam a composição; não fazem parte do aplicativo. Os assets não contêm dados, rótulos, botões ou personagens. Todo conteúdo e toda interação permanecem no React.
